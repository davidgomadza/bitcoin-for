# **App Name**: Bitcoin Genesis Vault

## Core Features:

- Unique Wallet Generation: Generates millions of Bitcoin wallets starting with 'J6', 52 characters long, using numbers and letters, each pre-loaded with 8 BTC.
- 12-Word Password System: Implements a 12-word password system for wallet access, allowing users to initially access their wallet and then transfer the BTC to their own wallets.
- Secure Wallet Initialization: When the user deposits US$64 to the specified email (davidgomadza@hotmail.com), a wallet containing 8 BTC and the corresponding 12-word seed phrase are made available.
- Landing Page Integration: A zero-sale landing page advertises the BTC for sale, details deposit instructions, disclaims the AGT claims, and advises that verification will be provided by davidgomadza.
- Instruction Display: Presents a very clear and user-friendly explanation about how to proceed with the process and disclaimers that come with buying into the product.
- AGT Reward Display: Describes clearly what are the conditions needed to qualify to receive immortality: owning 8,000 bitcoin and how to own the product.

## Style Guidelines:

- Primary color: White (#FFFFFF) for a clean and modern look.
- Secondary color: Dark blue (#188ADE) for trust and reliability.
- Accent color: Green (#00FF00) for highlights and calls to action, representing growth and value.
- Headline font: 'Space Grotesk' (sans-serif) for a modern and tech-forward feel. Body font: 'Inter' (sans-serif) for readability.
- Use clean, minimalist icons related to Bitcoin and wallet security.
- Clean and straightforward layout emphasizing clear instructions and trustworthiness.
- Subtle loading animations to enhance the user experience.
